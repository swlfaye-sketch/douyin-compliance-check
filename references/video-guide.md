# 成片解析操作指引

> 对应 `scripts/extract_video.py`。本档解决三件事：**装什么、怎么跑、产出怎么读**。
> 若你只审文案，不必看本档，走纯文字审核即可。

---

## 一 何时需要解析成片

只有以下几类判断**必须**看成片，纯文字审核做不到：

| 要判断的事 | 为什么文字审不出来 |
|---|---|
| 是否真人出镜 | 口播稿里没有人物信息 |
| 是否纯录屏／图文卡片 | 同上，且这是被判低质与判软广的主因 |
| 画面里有没有文字、二维码、联系方式 | 画面文字不进口播稿 |
| AI 标注是否真的加在画面上了 | 标注须在画面上持续显示，写在简介里不算 |

**反过来，如果只是措辞问题，就不要解析成片**——解析要跑语音模型与图像识别，耗时远高于文字扫描。

---

## 二 依赖：装什么、缺了会怎样

脚本对依赖的处理是**逐项探测、缺哪项跳哪项**，不会因缺一个依赖就整体失败。

| 依赖 | 用途 | 缺失时的行为 |
|---|---|---|
| **ffmpeg / ffprobe** | 取时长分辨率、抽音频、抽帧 | **核心依赖**。缺失则无法解析，脚本会明确报出。必装 |
| **faster-whisper** | 语音转写（口播文字） | 跳过转写，其余照跑。若只需看画面形态，可不装 |
| **OpenCV**（cv2） | 人脸检出 | 跳过人脸检出，改为提示须人工看图判断 |
| **Pillow** | 拼图、黑边与色彩统计 | 跳过拼图与画面统计，仍会抽帧 |
| **tesseract** | 画面取字（OCR） | 跳过 OCR，其余照跑 |

**装法（按需）**：

```bash
# 语音转写
pip install faster-whisper

# 人脸检出与图像统计
pip install opencv-python pillow

# 画面取字（Windows 需另装 tesseract 本体并加入 PATH）
pip install pytesseract
```

> ⚠️ **不要为了跑通而一次性全装**。先跑一次，看脚本报缺什么，只补缺的那项。

## 三 语音模型：默认不联网

脚本的定位是**纯本地解析，素材不出本机**。因此语音模型走**本地优先**，且：

| 情形 | 行为 |
|---|---|
| 本地 HuggingFace 缓存里有对应模型 | 直接离线加载，**不联网** |
| 本地没有，但用 `--model base` 等更小的模型 | 同上，先离线尝试 |
| 本地没有且未加 `--allow-network` | **不下载**，如实报出，并给出三种补齐方式 |
| 显式加 `--allow-network` | 允许联网下载（与「纯本地」定位不符，请自行确认） |

**补齐模型的两种稳妥做法**：

1. 用体积更小的模型：`--model base`（默认是 `small`）；
2. 事先在能联网的环境下载好模型，放入 HuggingFace 缓存目录
   （Windows 一般在 `%USERPROFILE%\.cache\huggingface\hub`），之后即可离线使用。

> 模型越大转写越准、越慢。日常审核用 `small` 足够；`medium` 只在语速快、
> 口音重时才有必要。

## 四 怎么跑

```bash
# 完整解析（转写 + 抽帧 + 人脸 + 画面统计 + 取字）
python scripts/extract_video.py --video <成片路径> --model small

# 只看画面形态，不做转写（快很多）
python scripts/extract_video.py --video <成片路径> --skip-asr

# 只审文字，画面另看
python scripts/extract_video.py --video <成片路径> --skip-frames --skip-ocr

# 抽更多帧（时长较长、画面变化快时）
python scripts/extract_video.py --video <成片路径> --frames 12
```

**参数一览**：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--video` | 必填 | 成片路径，支持中文路径 |
| `--out` | `<成片目录>/_review` | 产出目录 |
| `--model` | `small` | 语音模型：base / small / medium |
| `--frames` | `8` | 抽帧数量 |
| `--lang` | `zh` | 转写语言 |
| `--max-seconds` | `0`（全片） | 只处理前 N 秒，用于长视频快速初筛 |
| `--allow-network` | 关 | 允许联网下载语音模型 |
| `--skip-asr` / `--skip-ocr` / `--skip-frames` | 关 | 分别跳过转写／取字／抽帧 |

## 五 产出怎么读

产出全部写入 `--out` 指定的目录（默认 `<成片目录>/_review/`）：

| 产物 | 内容 | 怎么用 |
|---|---|---|
| `contact_sheet.jpg` | **关键帧拼图**（在产出目录**根下**，不在 `frames/` 内） | **必须用 Read 打开看图**，这是判断画面形态的唯一可靠办法 |
| `frames/` | 逐帧原图 | 拼图看不清细节时看单帧 |
| `transcript.txt` / `transcript.srt` | 口播全文与时间轴 | 复制到 `scan_text.py` 做措辞扫描 |
| `ocr.txt` | 画面文字识别结果 | 查画面里的联系方式、二维码旁文字、AI 标注 |
| `review.md` | 人读汇总 | 时长、分辨率、帧间差异、黑边、画面统计、人脸占比、字数 |
| `review.json` | 机器汇总 | 接自动化流程时用 |

### 5.1 画面形态判定：四类信号怎么配合

**这四项都是信号，不是判据。判定必须看图。**

| 信号 | 偏低／偏高的含义 | **不能据此单独下结论** |
|---|---|---|
| **人脸检出占比** | 为 0 即无人脸 | 侧脸、背影、遮挡、远景小脸都可能检不出，须看图 |
| **帧间差异均值** | 偏低（< 3）说明画面高度静止 | 纯录屏、图文卡片、静态图文**三类都会偏低**，三者只能靠看图区分 |
| **黑边（上下／左右条带）** | 多数帧检左右条带，提示可能是横屏转竖屏 | 原生竖屏留白、设计性边框同样会检出 |
| **色彩丰富度**（占用色格数、最大单色占比） | 色格少、单色占比高，提示可能是模板图文卡片 | 纯色背景的简约实景会同样偏低 |

**看图的判据顺序**（按此顺序问自己）：

1. 画面上有没有**真人面部**？没有 → 记「无真人出镜」；
2. 是**实景拍摄**还是**屏幕内容**？有状态栏、鼠标、竖向黑边 → 偏录屏；
3. 画面是不是**一块块文字卡片**、没有场景？→ 模板图文卡片；
4. 画面里的**文字**有没有联系方式、二维码、AI 标注？

> 📌 判低质的从来不是某一项数值，而是「**无真人 ＋ 无实景 ＋ 无实质信息**」这个组合。
> 差异小、人脸 0、色格少，都只是往这个组合上靠的证据，不是结论本身。

### 5.2 人脸检出为什么不报原始数字就下结论

人脸检测会**误报**——画面中的吊臂、圆形招牌、抱枕图案都可能被判成人脸。
脚本做了两级过滤（尺寸门槛：人脸框短边须达画面短边的 10%；眼部确认：框内须检出眼睛），
**同时列出未过滤的原始检出数**，便于你判断这次的数字可不可信。

## 六 常见问题

**问：脚本报「未安装 ffmpeg」怎么办？**
ffmpeg 是核心依赖。Windows 可用 `winget install Gyan.FFmpeg`，装完重开终端。

**问：转写结果错字很多。**
语音转写对口音、专业名词、背景音乐都容易出错。**转写只作线索**，涉及判定的关键句须回听原片确认，不要直接拿错字去判断违规。

**问：明明有真人，人脸却报 0。**
见 5.1：侧脸、遮挡、远景小脸、戴帽子口罩都可能检不出。**以看图为准**。

**问：跑一次要多久？**
取决于时长与模型。75 秒的竖屏短视频、`small` 模型，通常一两分钟。**长视频先用 `--max-seconds 60` 初筛。**

**问：能不能批量解析多个成片？**
脚本一次处理一个文件。批量请用 shell 循环，或只对「已通过文字审核、只剩画面存疑」的那几条跑解析。
