# 品类加严清单

> 用途：通用标准对**所有账号**成立；但同一句措辞在不同品类的后果不同。本文件给出**各品类的额外限制**。
> 用法：账号信息卡里选定品类后，审核时**叠加**本文件的附加条目（通用清单仍全部适用）。
> 规则依据截至 **2026-09-25**　｜　依据分级见 `platform-rules-sources.md`

---

## 〇 先用三问定位品类

不必纠结"我到底属于哪个品类"，回答三个问题即可：

1. **我这条内容里有没有"建议别人做什么"的成分？** 有 → 看是否落入**建议类**（医疗、金融、法律、教育）。
2. **我这条内容是不是为了卖东西？** 是 → 按**带货与商业内容**处理。
3. **我这条内容是不是教别人获得某种能力？** 是 → 按**知识付费与课程类**处理，且**这是 2026-09 被点名的方向**。

三项都不沾 → 按通用标准处理即可，不必套用本文件。

---

## 一 医疗健康类 🔴 最严

| 附加限制 | 说明 |
|---|---|
| **资质前置** | 涉及诊疗、药品、医疗器械、保健食品的，须有对应资质且完成平台报备。无资质一律不做 |
| **不得出现诊断或治疗建议** | 包括"你这个情况应该是……""建议吃 XX""三招治好" |
| **不得承诺疗效** | "根治""治愈率""无副作用""替代手术" |
| **不得用患者形象做效果见证** | 含患者自述、前后对比图 |
| **科普与建议的界线** | 讲机制、讲原理属科普；**一旦落到"你该怎么做"即越线** |
| **AI 相关特别注意** | "AI 看病""AI 读片""AI 开方"属高危，即使加了免责声明也不降低判定 |

**安全改法**：把"你该怎么做"改为"我的个人情况是怎样的"；把疗效承诺改为过程陈述；加"不构成医疗建议"不改变判定性质，但仍是必要的补充。

---

## 二 金融理财类 🔴 最严（被点名品类）

| 附加限制 | 说明 |
|---|---|
| **资质前置** | 证券投资咨询、基金销售、保险经纪、贷款中介均须牌照与报备 |
| **不得荐股、不得给具体买卖建议** | 含"这个可以买""目标价 X 元""跟着我操作" |
| **不得承诺收益** | "稳赚""保本""年化 X%""无风险" |
| **不得宣传征信修复、债务优化** | 属明令治理的灰色业务 |
| **不得推广虚拟货币、境外券商、外汇平台** | 涉跨境与非法金融活动 |
| **收益截图的处理** | **晒收益截图本身就构成诱导**，即使标注"不构成建议"也不降低判定 |

**安全改法**：只讲公开信息与个人理解，不给操作建议；去掉一切收益数字与"跟着做"的结构。

---

## 三 知识付费与课程类 🔴 被点名品类

**2026-09 官方明确把"理财、兼职和 AI 课程类引流"列为站外导流重点打击方向。** 本类内容的风险不在某一句话，而在**内容结构本身**。

| 附加限制 | 说明 |
|---|---|
| **"教你"结构是核心风险** | 凡构成"教人获取某项能力"的表达均计，**不限"课程"二字**：教程、教学、带练、手把手、保姆级、保姆教程、零基础、从入门到精通、跟我学、一步一步 |
| **仅替换同义词无效** | 把"教你"换成"分享"，若仍是教学结构，风险不降。**必须改变结构**——改为个人过程陈述 |
| **不得承诺学会、见效、变现** | "包教包会""学完能接单""三个月转行" |
| **不得引导加群、领资料** | 属导流主线 |
| **AI 工具类特别注意** | "三分钟教你怎么用这个 AI 做表格"属**双重命中**（教程结构 ＋ 被点名品类） |

**安全改法对照**：

| 危险写法 | 安全写法 | 关键差异 |
|---|---|---|
| 三分钟教你怎么用这个工具做表格 | 我拿它做了个表格，前后花了十来分钟，说下我的用法 | 去掉教学结构，改为过程陈述 |
| 手把手带你入门 | 这是我第一次用它，踩了两个坑 | 去掉"带你"结构与承诺 |
| 零基础也能学会 | 我之前完全没用过，说下感受 | 去掉能力承诺 |

## 四 带货与商业内容 🔴

| 附加限制 | 说明 |
|---|---|
| **商业内容须报备** | 商单、植入、品牌合作须走平台报备通道，不报备易判营销号 |
| **不得站外成交** | 引导私加微信下单、外链成交同时构成引流红线与交易风险 |
| **价格表述须可核验** | 原价、折扣、限时须真实，虚构原价属价格欺诈 |
| **不得虚假紧俏** | "最后三件""马上涨价""仅限今天"若无事实依据即违规 |
| **特殊类目资质** | 医疗器械、药品、保健食品、化妆品功效、金融、教育、房产、招聘均须资质 |
| **不得诱导互动** | 点赞抽奖、扣字送、关注解锁 |
| **不得删改差评、伪造评价** | 属虚假宣传 |
| **未成年人不得出镜带货** | 尤其不得代言与其年龄不符的商品 |

## 五 教育与培训类 🟡

| 附加限制 | 说明 |
|---|---|
| **不得承诺升学、保过、押题** | 属虚假承诺 |
| **不得制造教育焦虑** | "再不学就晚了""别人家孩子都学了" |
| **机构招生须资质** | 学科类培训另有专门监管要求 |
| **未成年人出镜** | 须监护人同意，且不得暴露学校、班级、住址 |
| **成绩与排名** | 不得公开他人成绩与排名 |

---

## 六 房产、招聘与本地生活 🟡

| 品类 | 附加限制 |
|---|---|
| **房产** | 房源信息须真实；不得虚构低价房源引流；不得承诺升值 |
| **招聘与兼职** | **须核验主体资质**；不得发布刷单、代运营、拉人头分销；"兼职"属 2026-09 被点名方向 |
| **本地生活与探店** | 收费探店须标注；不得虚构"排队三小时""本地人都不知道" |
| **餐饮** | 不得出现"最正宗""第一"；不得虚构成分与产地 |

---

## 七 母婴与儿童消费品 🔴

| 附加限制 | 说明 |
|---|---|
| **不得夸大功效** | 长高、益智、护眼、增强免疫力均属功效宣称 |
| **不得用"最安全""零添加"等绝对化表述** | 保健品与食品尤其严格 |
| **不得使用儿童形象做效果对比** | 涉及未成年人保护 |
| **不得推荐医疗器械类儿童用品** | 须资质与报备 |
| **婴幼儿食品** | 不得宣传替代母乳；不得针对 0 至 6 月龄配方食品做广告 |

---

## 八 科技与 AI 工具类 🟡

| 附加限制 | 说明 |
|---|---|
| **教程类表述升为最高级** | 属被点名品类，见第三节 |
| **海外产品的三条铁律** | ① 不带"国际版／海外版／翻墙"；② 不带"上线／发布／下载／注册"等行动词；③ 只说功能体验，不说怎么获取 |
| **平台内部规则属敏感话题** | 讨论计费、积分、倍率、算法权重、封号机制，与低质画面叠加会加重判定 |
| **不得伪造演示效果** | 用 AI 伪造产品效果、篡改截图属绝对红线 |
| **AI 内容标注** | AI 配音、AI 画面、数字人均须标注，见通用清单 3.3 |

## 九 如何新增一个品类

本文件不追求穷举。遇到新品类时，按四步补入：

1. **查前置资质**：该品类的经营是否需要牌照，平台是否要求报备；
2. **查是否被点名**：该品类是否出现在近期的专项治理方向上；
3. **找"建议"与"分享"的界线**：该品类里，哪些表述等于提供了专业建议；
4. **找绝对化红线**：该品类里哪些效果承诺是绝对不能说的。

补充后**写回本文件**，并在 `platform-rules-sources.md` 记下核对日期。
