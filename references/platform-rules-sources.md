# 规则依据与核对记录

> **核对日期：2026-09-25**　｜　核对方式：官方文档原文检索 ＋ 权威媒体交叉比对
> **有效期：建议一个月内复核一次。** 平台规则变动频繁，超过一个月未更新，本技能的判定需重新校验后再使用。

## 一、依据分级说明

判断一条规则能不能作为硬判据，先看它的依据级别：

| 级别 | 含义 | 用法 |
|---|---|---|
| **A** | 平台官方文档、公告、规则原文（含开发者平台、电商学习中心、创作者服务平台） | 可直接作为硬判据 |
| **B** | 官方口径的权威转述（主流媒体、官方账号解读） | 可作为判据，但表述须留余地 |
| **C** | 行业梳理、第三方分析 | **只作方向参考，不得作为硬判据** |

**凡本技能中作为硬判据的条目，均须为 A 级或 B 级。** 依据不足的，正文中已标注为"方向性"而非"既定事实"。

## 二、逐条核对结果

### 2.1 AI 内容标识 —— A 级

| 项 | 内容 |
|---|---|
| **规则** | 只要作品中存在 AI 参与生成的部分（AI 配音、AI 画面、AI 剪辑字幕、数字人、AI 撰写脚本）即需标注，**不以占比为条件**；仅当画面与声音均为真人实拍实录时无需标注 |
| **依据** | ① 国家网信办、工信部、公安部、广电总局联合制定《**人工智能生成合成内容标识办法**》，2025-09-01 施行；② 抖音《**关于升级 AI 内容标识功能的公告**》，2025-09-01 生效 |
| **级别** | **A**（法规 ＋ 平台公告双依据） |
| **核对结论** | ✅ 成立。**"占比超过 30% 才需标注"的说法未找到任何官方出处，已删除** |
| **处置** | 未标注时平台**辅助添加标识**（检测到疑似 AIGC 会加"疑似使用了 AI 生成技术，请谨慎甄别"；核验出元数据隐式标识会加"作品含 AI 生成内容"）；**累计 5 条及以上未标识，限制账号内容曝光**；情节严重或造成恶劣影响，扣除信用积分、禁言，直至限制访问 |

> 📌 **一处值得注意的细节**：平台会辅助加注，**但这不构成"不标也没事"的理由**——辅助标识是平台行为，创作者仍负有主动声明义务；且累计未标仍会被限制曝光。

### 2.2 标注入口 —— A 级

| 项 | 内容 |
|---|---|
| **规则** | 作品发布界面 → **高级设置 → 发文助手自主声明 → 内容由 AI 生成**；或在片头片尾加文字标识 |
| **依据** | 抖音《关于升级 AI 内容标识功能的公告》原文表述 |
| **级别** | **A**（路径）／**B**（"持续不少于 2 秒"的时长要求） |
| **核对结论** | ✅ 成立。**"创作者中心 → 发文助手 → 快速检测"是检测功能，不是标注入口**，属功能混淆，已更正 |
| **补充** | 数字人账号需**实名注册**；数字人出镜须在画面显眼位置标明身份；虚构演绎须在**画面上**标注 |

### 2.3 录屏／截屏属低质内容 —— A 级

| 项 | 内容 |
|---|---|
| **规则** | 不得出现低制作成本、音画不相关、无明确主题、无信息价值、无主旨随拍、过时内容、**录屏／截屏**等低质内容 |
| **依据** | 抖音开放平台《**短视频创作者管理规范**》内容质量低质条；《**短视频挂载使用规范**》4.4.1 |
| **级别** | **A**（两处官方文档互相印证） |
| **核对结论** | ✅ 成立。**录屏被官方明文列为低质内容类型** |
| **同条另含** | 「不得发布观赏性低且无实质意义的内容，如无互动的合拍、视频时长过短或**全程为黑屏／白屏**等无意义内容」；官方示例明确点名「**单图 ＋ 大量文字，创作成本低**」与「**图片轮播、模板感强**」 |

### 2.4 带货场景下禁止录屏与挂播 —— A 级

### 2.7 重复画风的具体判据 —— A 级（本次新增）

| 项 | 内容 |
|---|---|
| **规则** | 重复发布相同或相似内容，包括：① 账号下视频封面或主旨表达高度一致；② 经常重复发布同一个视频；③ 在相同或相似背景环境下批量制作形式单一内容相似的作品 |
| **官方示例** | 发布相同内容仅改封面／文字介绍／BGM；发布相同内容仅改文字表述；同一主体仅改背景；同一场景仅改拍摄角度；主旨内容完全一致仅调整素材片段前后顺序 |
| **依据** | 抖音开放平台《短视频创作者管理规范》重复画风条 |
| **级别** | **A** |
| **核对结论** | ✅ 成立。**这一条比"25%"更有用**——它给出了可直接比对的具体情形 |

## 三、复核清单（每次复核时逐条走一遍）

- [ ] **AI 标识**的判定标准、标注入口、未标处置有无变化（近年改动最频繁的一项）
- [ ] **站外导流的点名方向**是否更新（当前为五类，见 2.5）
- [ ] **录屏／挂播**的禁止范围有无扩大
- [ ] 是否有**新的专项治理计划**发布
- [ ] **健康分／信用分**的扣减梯度与违规大类有无调整
- [ ] **特殊行业要求**（教育、医疗、金融等）有无增补
- [ ] 本文件与 `compliance-rules.md`、`categories.md` 的核对日期是否同步更新

复核后须同步更新三处日期：本文件头部、`SKILL.md` 第〇节时效行、`compliance-rules.md` 头部。若品类规则有变，`categories.md` 头部一并更新。

## 四、不得作为依据的来源

以下来源**不得**用于支撑硬判据：

- **第三方解读、自媒体分析、他人帖子**——可作线索，须回溯至 A 级或 B 级来源；
- **另一平台的规则**——跨平台规则不可迁移（见 `compliance-rules.md` 第 19 节）；
- **本技能历史版本中的既有表述**——历史版本本身可能就有误（本轮即更正了三处：30% 阈值、标注入口、点名方向范围）；
- **带明确"由 AI 生成"声明的网页内容**——常含错误日期与不实细节，检索中已遇到（如把 2025-09-01 生效的法规写成 2026 年施行）；
- **单一来源的数值阈值**——凡数值（25%、30%、70% 之类），**须有官方文档原文方可作为硬判据**。
