# 发布前一页速查卡

> 不用跑脚本、不用读规则库，**发布前按这页过一遍**，能挡住绝大多数常见问题。
> 需要完整判定时再看 `SKILL.md`；需要机器初筛时用 `scripts/scan_text.py`。

---

## 第一步（必做，30 秒）：先定画面形态

**这一步在措辞之前。** 形态不过关时，改词是白改。

- [ ] 画面里**有没有真人**？（露出人脸、不是画外音）
- [ ] 是**实景拍摄**，还是**模板图文卡片**（PPT 式版式、纯文字卡）？
- [ ] 有没有**录屏痕迹**（手机状态栏、鼠标指针、界面元素、竖向黑边）？
- [ ] 画面有没有**手持晃动、对焦模糊**？

**判定**：

| 情形 | 结论 |
|---|---|
| 无真人 ＋ 无实景 ＋ 是**推荐／卖货**类 | ⛔ **不要发**，先补真人出镜 |
| 纯录屏 ＋ 推荐／卖货类 | ⛔ **不要发**（带货场景下录屏是明文禁止项） |
| 纯录屏 ＋ 其他题材 | 🔴 尽量补真人开场或收尾，不要全片录屏 |
| 有真人 ＋ 有实景 | 进入第二步 |

## 第二步（必做，1 分钟）：扫一眼这 12 条

**任一条打勾 → 必须先改。**

### 站外引流（最高优先级）

- [ ] 有没有**电话、微信号、QQ、邮箱、网址、二维码**？
- [ ] 有没有**"加我／私信我／私聊／进群／找我／联系我"**？（这些出现即判）
- [ ] 有没有**"扣 1／评论区自取／置顶评论／看主页"**？
      → 这一组**要看有没有搭配领取动作**：单说"大家有问题可以在评论区交流"没事；
      一旦与"资料／文档／链接／私信"同时出现，就是导流
- [ ] 有没有**"国际版／海外版／翻墙"**？
- [ ] 产品名后面有没有跟**"上线／发布／下载／注册／官网"**？
- [ ] 有没有**"教程／教你／手把手／带练／零基础／保姆级"**这类教学结构？
- [ ] 有没有引导去**别的平台**（公众号、小红书、B 站等）？

### AI 标注

- [ ] 用了 **AI 配音 / AI 生成画面 / 数字人 / AI 写脚本**吗？→ **必须标注**
      路径：发布界面 → 高级设置 → 发文助手自主声明 → 内容由 AI 生成

### 内容真实与措辞

- [ ] 有没有**"最强、第一、唯一、吊打、秒杀、100%、最低价、最便宜、独家、史无前例、万能神药"**这类绝对化用语？
      → 注意边界：**"第一名"算，"第一步"不算；"万能神药"算，"万能公式"不算**
- [ ] 有没有**效果承诺**（"保证有效""三天见效""包教包会""包退""稳拿"）？
- [ ] 有没有**"永久免费""稳赚""必过""保证月入过万"**这类承诺？
- [ ] 有没有**虚构原价**（"原价 999 只要 9 块 9"）？拿不出真实成交记录就别写
- [ ] 有没有**虚假紧俏**（"最后三件""马上涨价""仅限今天""抢完为止"）？——出现即判
- [ ] 有没有**"震惊！""万万没想到！""家人们谁懂啊"**这类强情绪钩子？
- [ ] 有没有**卖惨、编故事、摆拍、假身份、假测评**？

### 隐性雷区（最容易漏）

- [ ] 讲价格／优惠，有没有加**"截至 X 月 X 日，以官方为准"**？
- [ ] 有没有**为了拉完播而扣着结论不说**？（"看到最后有惊喜""重点在最后"——这是被点名的"内容不完整"违规）
- [ ] 正文里有没有提**平台规则、算法、限流、封号机制**？
- [ ] 要发的内容里有没有**地图**？→ 核对完整性、地名标注
- [ ] 用了**外部歌曲**吗？→ 换成平台自带音乐

## 第三步（必做，30 秒）：看另外三个地方

正文干净不等于安全。

- [ ] **简介**：有没有联系方式、外链、"看置顶"？
- [ ] **置顶评论**：有没有"需要资料的扣 1"这类引导？
- [ ] **画面上出现的文字与字幕**：和口播**同样**判定，别只顾着改口播稿

- [ ] 话题标签控制在 **3 至 5 个**，不要全是同一标签
- [ ] **AI 标注**勾上了吗（如适用）

## 十条最容易被忽略的

1. **拼音缩写、谐音不是护身符** —— 属"故意规避审核"，**加重情节**；正常措辞即可。
2. **AI 标注不看占比** —— 没有"不到 30% 就不用标"这回事，有 AI 参与就要标。
3. **累计算账** —— 累计 5 条及以上未标 AI，**限制账号内容曝光**；日更号几天就到。
4. **录屏在带货场景是明文禁止** —— 不是"低质"，是"作弊行为"。
5. **同质化看的是"一批"，不是"一条"** —— 同一模板连发十几条、同背景反复拍、素材切来切去重发，单条都"没违规"，合起来即违规。
6. **"内容不完整"是违规** —— 故意不讲重点、大字报只写一半，属被点名的诱导类型；**前 3 秒给结果**才对。
7. **给画面加蒙层、镜像、拉伸不降风险** —— 那是官方点名的"干扰审核"手法。
8. **晒收益截图本身就是诱导** —— 加"不构成建议"不降低判定。
9. **借用权威背书有专门禁令** —— 教育类不得借命题人、教授、学员的名义或形象作推荐证明，**即使是真的也违规**。
10. **不同平台规则不可互套** —— 某个平台要求缩写替代，不代表抖音也该缩写；**方向可能正好相反**。

## 什么时候该找完整版

| 情形 | 去哪里 |
|---|---|
| 要逐条判据 | `references/checklist.md`（十一类完整清单） |
| 要输出格式与判定口径 | `SKILL.md` 第四、五节 |

| 要查画面形态 | `scripts/extract_video.py`，然后**用 Read 看拼图**；操作见 `references/video-guide.md` |
| 想知道某句为什么报了／没报 | `references/wordlist-guide.md` |
| 属于医疗／金融／教育／带货等品类 | `references/categories.md` |
| 想知道某条规则的依据有多硬 | `references/platform-rules-sources.md` |
| 账号刚被处罚 | `references/compliance-rules.md` 第 16 节 |

## ⚠️ 一条总提醒

**扫描通过 ≠ 安全。** 词表是分级清单，不是穷举清单，未收录的表述同样可能违规。
这份速查卡与脚本都只是**发布前的自查**，判定权在平台。
