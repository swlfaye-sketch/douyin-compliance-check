# 输出模板

复制以下内容填写。**不保留空档**：无内容的档位整段删除，不要留空标题。

---

```
【抖音 · 发布前审核】

审核对象：〈文案文件路径 / 成片路径 / 直接粘贴〉
审核模式：文字审核（模式 A） / 成片解析（模式 B） / 批量（模式 C）
账号品类：〈品类，可多个；未配置则写"通用标准"〉
账号状态：〈正常 / 新号起量期 / 近期有违规记录〉
画面形态：真人出镜 / 无真人出镜 / 纯录屏或图文卡片 / 未检查
审核日期：YYYY-MM-DD

⛔ 建议放弃选题（如有则填，无则整段删除）
- 原因：
  1. 〈命中情形〉（依据：SKILL.md 4.2 第 X 项）
  2. 改写无法消除——〈说明为什么改不掉〉

🔴 必改
- 位置：〈标题 / 口播 / 文案 / 标签 / 简介 / 评论 / 私信 / 画面 / 直播〉
  原文："XXX"
  问题：XXX
  依据：〈规则条目，如 SKILL.md 3.1〉
  改成："XXX"

🟡 建议改
- 位置：XXX
  原文："XXX" → 问题：XXX → 改成："XXX"

🟢 提醒
- XXX

📋 发布前最后一步
1. AI 标注：若含 AI 配音／生成画面／数字人／AI 撰写脚本，须走
   发布界面 → 高级设置 → 发文助手自主声明 → 内容由 AI 生成
   （或在片头片尾加文字标识并持续不少于 2 秒）
2. 用抖音发文助手快速检测复测一遍（注意：其检测通过不等于安全）
3. 话题标签 3 至 5 个，不要全是同一标签
4. 简介、置顶评论、评论区话术同步检查（全链路）

✅ 结论：可以发 / 改完再发 / 换选题
```

---

## 填写规范

1. **位置必须写明**。只写"标题"或"口播"不够，若同一句在标题与口播中都出现，两处都列；
2. **依据必须落到条目**。写清命中的是哪一条（如"SKILL.md 3.1 教学结构"），不要只写"不合规"；
3. **改写必须给成品**。不要写"建议修改措辞"，要直接给出可用的新句子；
4. **画面形态先写**。它决定措辞改写的优先级——纯录屏／图文卡片叠加推荐类题材时，改词无效；
5. **账号状态要写**。处于升级档位时，判定结果与默认档不同，必须在报告里交代清楚；
6. **不建议加"祝发布顺利"之类的客套**。

## 判定档位速查

| 档位 | 判据 | 处置 |
|---|---|---|
| 🔴 必改 | 命中站外引流任一条；纯录屏／无真人／搬运；需标 AI 而未标；高危题材；虚假营销；版权与商业内容红线；未成年人保护红线 | 不改不得发布 |
| 🟡 建议改 | 极限词与价格表述；同质化与节奏；低质特征单项 | 改写后再发 |
| 🟢 提醒 | 无风险，按账号长期策略可优化 | 记下即可 |
| ⛔ 建议放弃选题 | 选题本身构成 🟡 及以上且改写无法消除 | 换选题 |

## 升级档位提示（按需加）

若账号处于以下任一状态，在报告开头**明确标注**：

| 状态 | 标注文字 | 处理 |
|---|---|---|
| 近期有违规记录／刚解封 | `账号状态：近期有违规记录，标准整体上调一档` | 原判 🟡 的按 🔴 处理 |
| 新号起量期 | `账号状态：新号起量期，高风险题材整体避开` | 先发安全内容养号 |
| 内容属被点名品类 | `品类提示：属被点名方向（AI 课程／股市预测／债务优化／兼职赚钱／线上开店投资）` | 相关条目一律按最高级 |
| 纯录屏或图文卡片 ＋ 推荐／营销 | `形态提示：无真人无实景，叠加推荐类题材` | 直接判 ⛔ 或 🔴，不再讨论措辞 |

## 批量审核的汇总写法

模式 C 扫完一批后，先给一张汇总表，再逐条展开：

```
批量审核汇总（共 N 条）

| # | 文件 | 必改 | 建议改 | 结论 |
|---|---|---|---|---|
| 1 | xxx.txt | 3 | 1 | 改完再发 |
| 2 | yyy.txt | 0 | 0 | 可以发 |
| 3 | zzz.txt | 6 | 2 | 换选题 |

共性问题（先统一改掉，再逐条看）：
1. ……
2. ……
```

**批量场景下优先处理共性问题**——往往一套模板措辞同时出现在多条里，改一处模板即解决大半。
